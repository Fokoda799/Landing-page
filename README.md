# Brainwave – Landing Page

A modern and responsive landing page built as a practice project to improve frontend development skills and prepare for freelancing work.

🔗 Live Demo: https://brainwave-project-1.vercel.app

---

## 📌 About the Project

This project is a **landing page website** focused on:
- Clean and modern UI
- Responsive design for all screen sizes
- Reusable components
- Smooth layout structure

---

## 🛠️ Built With

- HTML
- CSS / Tailwind CSS
- JavaScript
- React + Vite
- Vercel (Deployment)

---

## 🚀 Features

- Fully responsive layout
- Modern landing page design
- Clean component structure
- Deployed and accessible online
